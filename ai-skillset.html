AI-Assisted Engineering / Skill Matrix

AI活用開発に必要なスキルセット

「エンジニアとして一人前になる」「AIを組織に導入するのに十分な力をつける」の二つを土台に、個人の生産性ではなくエンジニア組織全体の能力として成立させるための一覧。基礎（Layer 00）から実務開発力・プロジェクト遂行力（Layer 01–02）、AI理解・実務・組織能力（Layer 03–11）まで、下から積み上がる構造です。太字＝チェック単位、その下の小さなタグ＝そこに含まれる具体的な要素。略語・カタカナ用語には赤字で日本語の注釈を付けています。

SAVING

自動保存
チェックするたびに、開いているブラウザへ自動保存されます。ファイルをダブルクリックで開き直しても復元されます。上部のランプが緑なら効いています。
注意
保存先はブラウザ内部の領域です。閲覧データを削除すると消えます。別のブラウザや別のPCへは引き継がれません。Safari では効かないため Chrome / Edge / Firefox を推奨します。
書き出し
チェック状態を JSON ファイルとして保存します。バックアップ、別のPCへの移動、Gitでの履歴管理に使えます。区切りのタイミングで実行しておくと安全です。
読み込み
書き出した JSON を読み込んで状態を復元します。ブラウザを変えた場合や、保存が効かない環境ではこちらを使ってください。
Markdown
チェック状態込みの Markdown を書き出します。Confluence や Obsidian にそのまま貼れます。

展開の順序

Layer 00–02（CS基礎・実務開発力・プロジェクト遂行力）を全員のボトムラインとして引き上げ、Layer 10（組織能力）で標準化と測定の仕組みを先に作る。Layer 06–07（エージェント設計・評価）は先行チームで実証してから横展開する——この順番が最も回りやすい構成です。Layer 00 は「AI時代に不要になる」のではなく、生成物を検証する力として重要度が上がる領域として扱ってください。Layer 01–02 は「一人前のエンジニア」の実務面の土台であり、AI活用の巧拙以前にキャリア全体を支える層として位置づけてください。
